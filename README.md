# 📚 StudyBuddy – Student Productivity Dashboard

A simple and interactive student productivity dashboard built using **HTML, CSS, and JavaScript**. StudyBuddy helps students manage their daily tasks, track their progress, and focus on their studies using a Pomodoro timer.

## 🚀 Features

* ✅ **Task Manager** – Add, complete, and delete daily tasks.
* 📊 **Progress Tracker** – View total tasks, completed tasks, and completion percentage.
* ⏱️ **Pomodoro Timer** – Focus on studies with a 25-minute countdown timer.
* 🌙 **Dark Mode** – Switch between light and dark themes.
* 📱 **Responsive Design** – Adapted for desktop and mobile screens.
* 🎨 **Clean UI** – Simple and user-friendly dashboard interface.

## 🛠️ Technologies Used

* **HTML5** – Website structure.
* **CSS3** – Styling, Flexbox, Grid, and responsive design.
* **JavaScript** – Task management, dashboard updates, theme switching, and timer functionality.

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/StudyBuddy-Dashboard.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser, or use the Live Server extension.

4. Start adding tasks and explore the dashboard features!

## 🎯 Project Objective

The objective of StudyBuddy is to help students improve their productivity and time management while practicing front-end web development concepts.

Through this project, I practiced:

* DOM manipulation and event listeners.
* Array methods such as `forEach()` and `filter()`.

## ⚠️ Current Limitations

* Tasks are stored in memory and reset when the page is refreshed.
* The Pomodoro timer supports a 25-minute countdown and reset.
* The project currently does not include a backend or database.
